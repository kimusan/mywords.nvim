# My Dictonary for Neovim

An easy to use neovim plugin that makes it easy to add words to a personal
dictionary and thereby make it easy to auto-complete them later on.
The plugin provides both a global and a per-project dictionary mode so
some words specific to a project do not get auto-completed in another project.

Words can easily be added to the list, removed from the list and the list
of words can be searched (with a fuzzy search if fzf-lua is available).
